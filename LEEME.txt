HORIZONTE TEMPORAL — WEB V02

Subir TODOS los archivos y la carpeta images a la raíz del repositorio prenuclear/horizonte-temporal.
En GitHub, reemplazar index.html, styles.css y script.js; agregar contenido.json y .pages.yml.
En Pages CMS, seleccionar el repositorio y editar «Contenidos de Horizonte Temporal».
La web carga contenido.json mediante fetch: para probarla localmente usar un servidor local o publicarla en Netlify; abrir index.html directamente desde el explorador puede impedir cargar el JSON.
Noticias: agregar elementos a noticias, con fecha AAAA-MM-DD.
Enlaces de venta: agregar elementos en compra.enlaces con URLs https:// reales.
Las imágenes deben existir en la carpeta images y se escriben con su nombre, por ejemplo 1000057951.jpg.
La web es estática: Pages CMS guarda cambios en GitHub y el alojamiento debe estar conectado para desplegarlos.
